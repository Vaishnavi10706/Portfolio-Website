## ⚙️ Installation

Clone the repository:

```bash
git clone https://github.com/Vaishnavi10706/Portfolio-Website.git
```

Navigate to the project directory:

```bash
cd Portfolio-Website
```

Install dependencies:

```bash
npm install
```

Start the development server:

```bash
npm run dev
```
